# EduX Starter

Build and publish your own website by describing it to a coding agent. You do not need to install anything or know how to code.

## Get started

1. Look for the **terminal** at the bottom of this window. When setup finishes, it shows a link.
2. Hold **Ctrl** (or **Cmd** on a Mac) and click the link. OpenCode opens in a new browser tab.
3. On the OpenCode home page, click the session about your **EduX project**.
4. Type in the chat box to start building.

**No link, or it stopped working?** Click in the terminal, type `edux` and press Enter to get a new one. Each link works once and lasts 5 minutes.

## Your two browser tabs

| Tab | What it is for |
| --- | --- |
| **This one (Codespace)** | Your files and the "Your website" preview |
| **OpenCode** | Chat with the agent, see its changes in Review |

Refresh the preview after each change. If you closed it, open the **Ports** tab at the bottom of this window and click the globe beside "Your website".

## Useful commands in OpenCode

| Type this | What it does |
| --- | --- |
| `/undo` | Reverses the agent's last change |
| `/model` | Changes the AI model. Stay on **DeepSeek V4.1 Flash** or **GLM-5.3-Flash** |
| `@` | Points the agent at a file |
| `/review` | Asks the agent to review your changes |

## Stay safe

- **Your website is public.** Do not include anything private.
- **Never paste an API key** into the chat, a file, or a message. It belongs only in Vercel's settings.
- **Save your work to GitHub.** Ask the agent to commit and push before you leave.

## Coming back later

Go to [github.com/codespaces](https://github.com/codespaces) and open this project. Stop the Codespace when you finish, to save your free hours.
